# Codebase Planner

<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
Tauri 2 desktop shell, React, TypeScript, Vite, React Flow, Rust, SQLite.

## Users
Individual developers organizing work across local repositories on macOS.

## Product purpose
Create todos, plan features, and track bugs through a shared hierarchy displayed as a mind map or list.

## Capabilities and constraints
Multiple local projects associated with repository folders. Markdown notes, status, priority, tags, related-item links, search, filters, persistent map positions, JSON backups. Single-user local storage with offline manual planning. Optional Codex subscription connection creates planner items and links from typed or system-dictated text, with cancellation and session-scoped batch undo. AI generation requires internet access. No repository scanning, source-code implementation, cloud sync, kanban, due dates, or automatic status rollups.

## Brand commitments
Light Codex surfaces and spacing combined with Obsidian's expandable navigation and connected items. System fonts, subtle borders, restrained accents. Implement directly, then inspect the running app.

## Accessibility
Keyboard-accessible list and editor offer equivalents for canvas actions. Visible focus, reduced-motion support, readable contrast.
